# 控制流

## 条件：if / else

- **if 表达式 / 语句**：`if (cond) { then } else { else }`，有返回值时 then/else 类型一致。
- **产品写法强制括号**（2026-09-08）：`if (cond) { … }` 与 `while (cond) { … }`。条件整式一律包在关键字后的 `(` … `)` 里，然后才是 `{`。禁止产品源 `if cond {`（无包裹括号）。
- **子表达式分组写在包裹括号内**：`if ((x >> 2) != 4) { … }` / `while ((x << 1) != 0) { … }`。禁止产品源 `if (x >> 2) != 4 {`（wave650 裸分组当条件）。
- **parser 仍接受历史形式**（wave361/650 探针）：bare `if cond {` 与 `if (primary) binop {` 仍能解析，扫句器回归见 `tests/probes/wave924/if_paren_binop_assign.x`。新产品、compiler、std **不得**再写。if 后还可接其它语句（wave362）。
- **else 可选**：若省略 else，则按「否则为 0」等规则处理（具体以 typeck 为准）。
- 条件 `cond` 须为 `bool` 类型（禁止整型隐式转 bool）。
- **IDENT + `{` 消歧**：条件里的 `b { body }` 中 `b` 为变量。**值位置结构体字面量权威 = 匿名** `{ field: e }`（见 docs/04）；`Type { field: e }` 可能被 parser 收成 STRUCT_LIT，但 **typeck 拒绝**（写 `let x: Type = { field: e }`）。
- **FIELD_ACCESS + `{` 消歧**（wave370）：条件末位为字段/枚举变体时，产品写法 `if (a.x) {…}` / `if (1 == b.x) {…}` / `if (c == Color.Red) {…}` / `while (b.x != 0) {…}`；`{` 留给 then/while 体。历史 `Module.Type { field: e }` 路径仍可能 parse 为 STRUCT_LIT（与 IDENT 共用 G.7 `lbrace_looks_like_block`），**产品写法用匿名 lit + dest 类型**，勿依赖 named 值位置。
- **空体**（wave364）：`if (b) {}` / `while (b) {}` 合法。空结构体值写 **`let e: S = { }`**（匿名）；parser 对 `S {}` 的值位置消歧仍在，但 typeck 拒 named 形式。
- **STRUCT_LIT 末字段空嵌套**（wave367）：`let a: A = { x: 42, e: { } }` 合法（内层 Empty dest 自字段类型）。field 值解析深度下，内层 `{ }` 后的外层 `}` 仍保持 struct lit（不与 if/while 空体 prefer-block 冲突）。**禁止**值位置 `A { x: 42, e: Empty {} }`。

示例：

```su
let x: i32 = if (a > 0) { 1 } else { 2 };
```

## 循环：while / loop / for

- **while**：`while (cond) { body }`（括号同 if，产品强制），条件须为 `bool`。
- **loop**：`loop { body }`，等价于 `while (true) { body }`。
- **for**：C 风格 `for (init; cond; step) { body }`；init/cond/step 均可省略（cond 空表示恒真）。

在循环体内可使用：

- **break**：跳出当前循环。
- **continue**：进入下一轮循环。

示例：

```su
let n: i32 = 0;
for (let i: i32 = 0; i < 10; i = i + 1) {
  n = n + i;
}
```

## 多分支：match

- 语法：`match expr { pat => result; ... }`
- 分支形式：
  - 整数字面量：`1 => 2;`
  - 枚举变体：`Variant => expr;` 或 `.Variant => expr;`（类型来自 match 主语）；`Name.Variant => expr;` 仍接受
  - 通配：`_ => expr;`（其它情况）
- 每个分支以分号结尾；match 整体为表达式，有类型。
- **语句位置**（wave371）：函数/块中可写独立 `match expr { … }`（不必包在 `return`/`let` 里）；臂结果可为值、赋值或 `return expr`（与表达式 match 同一 AST）。
- host-C / freestanding（wave372）：含 `return` 臂的 **语句位** match 发 if/else 真 `return`（其后可达语句不再执行）；**值位**（`return match …` / 三元）仍 unwrap 臂操作数。
- **块臂 + return**（wave374）：`=> { return N; }` / 多语句块内 `return` 与 bare `=> return N` 同为 return-control。函数末位 match、`return match {…}` 与中置 match 均发 if/else 真 `return`（禁止 `return (?:(({ return N; })):…)` 非法 C）。纯值块臂 `{ 42 }` 仍走值位三元 / final return。

示例：

```su
return match x { 1 => 2; 2 => 3; _ => 0; };

// statement form (mid-body or final)
match x {
  1 => return 2;
  _ => return 0;
}

// block arm with return (final or mid-body)
match x {
  1 => { return 42; };
  _ => { return 0; };
}
```

## 延迟执行：defer

- **defer 块**：`defer { block }`，在**当前块退出时**逆序执行所有已注册的 defer 块。
- 用于清理资源、保证执行顺序等。

## 跳转：label 与 goto

- **标签**：`label_name: stmt`
- **goto**：`goto label_name;`，跳转到同函数内该标签处。
- 与 return 等组合可表达显式控制流。

## 返回与终止

- **return**：`return;` 或 `return expr;`。有返回类型的函数须显式 return 带值；**void** 函数用 `return;`。入口 **main** 可为 `i32`/`i64`（退出码）或 **`void`（隐含 exit 0）**。
- **panic**：`panic;` 或 `panic(expr);`，终止程序；可选消息。  
  - ABI：`void xlang_panic_(int has_msg, intptr_t msg_val)`（host-C / runtime_panic；LP64 指针全宽）。  
  - **整数**（如 `panic(42)`）：`has_msg=1`，`msg_val` 为整型；runtime 打印 `panic: <n>` 后 abort/exit（host-C `fprintf`；Linux freestanding `.s` itoa+`write(2)`，wave389）。  
  - **字符串 / `*u8`**（如 `panic("boom")`）：`has_msg=2`，`msg_val` 为 cstr 指针；runtime **完整打印** `panic: <msg>` 后 abort/exit（wave386）。  
  - 无参 `panic` / `panic()` → `xlang_panic_(0, 0)`。
